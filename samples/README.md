# samples/

All data in this folder is fictional (MIT hackathon demo, Suyana track).

- `sample_farmers_10.xlsx`: a loan book of 10 fictional farmers for the 2022/23 La Niña drought season in Argentina, Uruguay, Brazil and Paraguay, each with a distinct credit story (uninsured, parametric cover, hail-only cover, restructured, defaulted, control case). Sheets: README, CreditStory (narrative and what the monitor should show), then Farmers, Fields, Loans, Repayments, Insurance, CreditHistory in the format of `docs/CONTRACT.md` section A. Load it on the Load loans page or with `python3 backend/pipeline.py --book samples/sample_farmers_10.xlsx`.
- `loan_book_template.xlsx`: the blank template a bank fills in. It has an instructions sheet (required vs optional columns, defaults, value lists), the six contract sheets with header notes, drop-downs and one greyed EXAMPLE row each, which must be deleted before loading.
- `ifrs9_parameters.xlsx`: the IFRS 9 model parameters (PD and LGD tables, SICR multiplier, scenario weights, discount rate and so on) that the bank can edit to calibrate the provisions to its own data. Created by the backend.
- `ifrs9_provision_report_example.xlsx`: an example of the IFRS 9 provision report the platform outputs (stage, PD, LGD, EAD and ECL per loan and portfolio totals). Created by the backend.
- `make_samples.py`: the generator for the first two files. Regenerate with `python3 samples/make_samples.py` (needs openpyxl).
- `reports/`: example PDFs generated by `backend/loanly/pdf_reports.py` as of the default week (18 Jan 2023): `portfolio.pdf` (IFRS 9 provision report), `early_warning.pdf`, and for two loans a loan memo plus the action documents (claim, restructure, downgrade/Stage 2 memo, transfer, cover offer, borrower call brief, insurance application). `*_L047.pdf` is an insured loan with triggered parametric cover (so it also has the insurance claim notice); `*_L004.pdf` is an uninsured Severe soy loan (so the cover offer and insurance application apply). Regenerate through `GET /api/pdf/<kind>`.
