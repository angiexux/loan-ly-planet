# Loan-ly Planet

Climate risk monitor for agricultural loans (MIT Energy & Climate Hack 2026, Suyana track).
It shows a lender which farm loans are under climate stress, why, and what that does to IFRS 9 provisions.

![One season in the soil: sensor readings, alerts and the effect on the loan](docs/sensor-animation.gif)

## Run it

```
web/run.sh            # http://127.0.0.1:5173
```

`run.sh` uses a bundled Node 22 in `web/.tools/` (not in the repo; with your own Node 20+, run `npm install` and `npm run dev` in `web/`, and `python3 backend/server.py` for the API). It regenerates the demo data if it is missing.

## Layout

| Path | What |
|---|---|
| `web/src/App.tsx` | All pages: landing, Portfolio, Alerts, Loan drill-down, IFRS 9 reports, Actions, Load loans, Methodology & back-test |
| `web/src/model.ts` | The model: stress score, analog yield outlook, climate-adjusted PD / Stage / LGD / ECL, alerts, back-test, CSV upload |
| `web/src/PortfolioMap.tsx` | Leaflet map (adapted from Faraday's `sitemap.tsx`) |
| `web/src/charts.tsx` | SVG charts (adapted from Faraday's `charts.tsx`) |
| `web/src/index.css` | Faraday look: Big Shoulders + Inter, orange accent, pill nav, sidebar dashboard |
| `pipeline/generate_portfolio.py` | Synthetic portfolio → `web/public/data/portfolio.json` |
| `reference/` | The Faraday/Powerllel sources this was built from, kept for reference |

## Data

`portfolio.json` is **synthetic**. It holds 240 loans of a fictional lender in Argentina, Uruguay, southern Brazil and Paraguay, generated by a toy crop model to replay the 2022/23 La Niña drought. Each field has 36 dekads (10-day periods) of NDVI, rain, temperature, frost, soil moisture, flood and hail data, plus 20 past seasons of history. Defaults are simulated and are used only in the back-test.
